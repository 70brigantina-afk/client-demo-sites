# Три демо-сайта

Самостоятельные сайты для презентации: падел-клуб, косметология Ральф и образование.

## Публикация
В Settings → Pages выбрать Source: Deploy from a branch, Branch: main, Folder: /docs, затем Save. Готовая статическая версия находится в `docs/`. Публикация не требует ChatGPT, базы данных, ключей или внешних API.

## Разработка
Node.js 22+, `npm install`, `npm run dev`. Для обновления: `npm run build`, заменить содержимое `docs/` содержимым `out/`, сохранить файл `.nojekyll`, отправить изменения в main.

Базовый путь: `/client-demo-sites`. При переименовании репозитория изменить `next.config.mjs` и ссылки в компонентах.

## Ограничения
Это концепции, не официальные сайты организаций. Формы работают в тестовом режиме: не отправляют заявки и не бронируют реальные услуги. Фотографии концептуальные. Проверенные исходные сведения и недостающие данные описаны в project-notes/source-register.md и на странице /review. Демо закрыты от индексации.
